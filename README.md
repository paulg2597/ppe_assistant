# ppe_assistant
Dein digitaler Studiengangsberater für den PPE-Bachelor an der UDE. Ich beantworte Fragen zu Modulen, Studienaufbau, Prüfungsorganisation und Ansprechpersonen auf Basis von Prüfungsordnungen, Modulhandbuch, Website und Wiki. Meine Auskünfte sind unverbindlich – maßgeblich sind die Originaldokumente. Bitte gib keine persönlichen Daten ein.
